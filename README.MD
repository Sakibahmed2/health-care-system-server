# 🏥 Health Care System

PH HealthCare is a web-based healthcare management system that connects **patients**, **doctors**, and **admins**. It allows users to book appointments, manage medical records, and communicate in real time.

---

## ⚙️ Features

- 👩‍⚕️ Admin can manage doctors and appointments
- 🩺 Doctors can view patients, create prescriptions, and handle schedules
- 👤 Patients can book appointments, upload reports, and pay online
- 💬 Real-time video calls using WebRTC (Agora.io)
- 💳 Secure payments and email notifications

---

## 🛠️ Tech Stack

- **Backend:** Node.js, Express.js, Prisma
- **Database:** PostgreSQL
- **Other:** Stripe, Agora.io, Nodemailer
